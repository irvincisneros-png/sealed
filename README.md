# SEALED

Year 8 Data Science (NSW 8.2.2, 8.2.3) game: probe a sealed vault, build a model from your data, then see how close it was.

- Six hand-authored cases, bounce / x-ray / scale / thermal probes
- Blueprint painting, live "Check model", new-data round, reveal, stars and cards
- Vanilla ES modules + vendored three r170, no build step, no network calls

Run: `python3 devserver.py 8490` then open http://localhost:8490/
Test: `npm test` (logic and case solvability, node --test)
